# Desk Scout downloads

Official download home for **Desk Scout Companion** and Desk Scout device firmware.

## Current release status

No consumer release is published yet. Downloadable builds will appear on the [Releases page](https://github.com/aideskscout/desk-scout-downloads/releases) only after the macOS app is signed and notarized and each target-specific firmware image passes signing, rollback, and USB recovery validation.

This repository contains release binaries and release notes only. Product source code, signing keys, certificates, diagnostics, and user data are never published here.

## Safety

Only install assets attached to releases published by the `aideskscout` account. Do not install files shared through issues, comments, forks, or third-party mirrors.
